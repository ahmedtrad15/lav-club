## 6. The Store (Product Selection)

**Principle:** easy and direct — **no categories**, everything on one screen.

- Each product is represented by an **icon** (no real pictures).
- Flow per product:
  1. User clicks an icon (e.g. 👖 trousers)
  2. Selects the **quantity**
  3. Clicks **Add to cart**
- Repeat for any other item.

**Pricing:**
- Each product has a **fixed washing price** (full list in section 10).
- The total is **calculated and displayed automatically** as the user adds items.

**Special products (highlighted):**
- **Wedding dresses: 60 DT per dress**, in a dedicated, visually highlighted section — this targets bridal businesses.

**Discounts (they don't stack — the best one applies):**
- **-30 %** on the first order placed on the website.
- **-10 % on the whole order** from **4 normal items** (wedding dresses, carpets and curtains don't count toward the 4).
- Discounts apply to items only, never to fees.

**Upsells:** later.

## 7. Ordering Flow

### 7.1 Pickup

- Pickup is always **the day after** the order is placed, **7 days a week** (Sunday included).
- The user chooses a time slot:
  - **10:00 – 12:00**
  - **16:00 – 19:00**
- *Not available at these times? Contact us.*

### 7.2 Delivery

The user picks their delivery date with a **date picker**. Same time slots as pickup (10–12 / 16–19). **No deliveries on Sunday.**

| Option | Earliest delivery | Extra cost |
|---|---|---|
| **Standard** | 48 hours after pickup | Included |
| **Express ("Je suis pressé·e")** | 24 hours after pickup | **1 DT per item**, or **10 DT flat from 5 items** |

The date picker only allows valid dates for the selected option.

### 7.3 Fees & payment

- **10 DT** for pickup + delivery, once per order.
- **Cash on delivery** only.
- Orders reach the shop by **WhatsApp** (and e-mail once an address is configured).
- Site language: **French**.

### 7.4 Summary of the customer journey

```
Home → Pick items (icons + quantity) → Cart (auto total, discounts, upsells)
     → Address (must be in service area) → Pickup slot (tomorrow, morning/evening)
     → Delivery option (Standard / Express) + date → Send order on WhatsApp
```
